## Instagram Reel / Facebook Reel
Ever wondered how a captcha knows you're human? 🤖❌ 🙋✅

1️⃣ The server creates a random code
2️⃣ It draws it twisted with noise, so bots can't read it
3️⃣ You type what you see
4️⃣ The server checks the match. Match = human, access granted ✅
